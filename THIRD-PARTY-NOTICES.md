# Third-party notices

Roulette 47 is built with the components below. Each one stays under its own
license; the Roulette 47 license (`LICENSE`) does not apply to them.

| Component | Used for | License |
|---|---|---|
| [nlohmann/json](https://github.com/nlohmann/json) 3.11.3 | JSON reading and writing | MIT |
| [miniz](https://github.com/richgel999/miniz) 3.0.2 | gzip decompression of server responses | MIT |
| Hacker Disassembler Engine 64 (`hde64`), from [MinHook](https://github.com/TsudaKageyu/minhook) 1.3.3 | measuring instructions before a hook | BSD 2-Clause |
| [Microsoft WebView2 SDK](https://www.nuget.org/packages/Microsoft.Web.WebView2) 1.0.2903.40 (`WebView2LoaderStatic.lib`) | the in-game overlay | BSD 3-Clause |

The libraries are downloaded at build time (CMake, `tools/recuperer_webview2.ps1`);
none of their source code is stored in this repository. Release builds link
them statically, hence the notices below.

No code from any HITMAN modding framework is included. The layout of the game
data the mod reads is described in `src/Glacier.h`, written for this project.
